顾名思义，就是把线段树这个数据结构拖过来持久化了

可持久化线段树的作用

基于可持久化线段树，我们可以拓展出：

  • 可持久化数组
  • 可持久化队列（过于少见）
  • 可持久化栈（过于少见）
  • 可持久化并查集

不过应用最广泛的还是可持久化线段树本身

可持久化线段树

假设我们需要维护一个求和线段树，支持：

  1. modify x d：在前一个线段树版本的基础上新建一个版本，并修改第 $x$ 个元素为 $d$
  2. query v l r：查询第 $v$ 个版本中，线段树中 $[l,r]$ 区间的元素的和

对于 modify 来说，由于线段树的单点修改只会影响大约 $logn$ 个点，所以我们新建一个版本时只需要新建大约 $logn$ 个点，其余节点复用以前的节点就行了

对于 query 来说，这是一种恒等操作，不需要新建任何东西，直接找到对应版本的线段树做查询即可
