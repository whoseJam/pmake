vector in C++

vector是C++提供的一种数据结构，需要使用头文件#include < vector >，可以把它理解为可变长的数组，基础操作如下：

操作 描述
push_back(x) 向vector末尾添加一个元素x
pop_back() 弹出vector最末尾的一个元素
size() 获取vector的大小
vector< type > a 定义一个名叫a，内部元素类型为type的空vector
  • vector< int > a;
  • vector< char > b;
  • vector< string > c;
