# 演示文档风格

## 语言与标点

-   使用中文编写，全篇不出现句号、冒号
-   避免大篇幅代码块，用动画或图示代替

## 内容组织

-   少文字，多动画：用简短短语或关键词，给老师留出讲解空间
-   启发优先：阐述“为什么”而非“每一步怎么做”
    -   讲题时，从更高维度说明思路来源
    -   讲模板时，分步展示代码并解释设计动机

## 目录结构

不同章节按文件夹拆分，示例（二分图最大匹配）

```
.
├── ppt.html                 // 入口
├── 二分图最大匹配概述
│   ├── ppt.html
│   ├── 匹配与最大匹配.js
│   ├── 染色.js
│   ├── 增广路.js
│   └── 最大匹配.js
├── 宫廷守卫
│   └── ppt.html
├── 矩阵游戏
│   ├── ppt.html
│   ├── 矩阵游戏.cpp
│   ├── 矩阵游戏问题转换.js
│   └── 矩阵游戏中的不变量.js
...
```

保持同级目录独立，资源就近放置，便于复用与维护。

章节不用以数字为序号——它们不需要序号，这样可以让 ppt 的组合更加灵活。
