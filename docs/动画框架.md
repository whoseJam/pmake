# SD 动画框架

SD 动画框架在 SVG 之上提供轻量级对象封装，将原始 SVG 元素映射为链式 JS 对象。以矩形为例：

```js
const svg = sd.svg(); // 1200×600 画布
const rect = new sd.Rect(svg); // 创建矩形
rect.x(100).width(30); // 链式设置属性
```

读取属性时，调用同名方法且不传参：

```js
console.log(rect.x()); // 100
```

## 动画区间

把属性修改置于 `startAnimate` / `endAnimate` 之间即可生成过渡动画：

```js
rect.startAnimate(300) // 0 ms 开始，持续 300 ms
    .x(100) // 目标值
    .width(30)
    .endAnimate();
```

多段动画按声明顺序依次执行：

```js
rect.startAnimate(200).… .endAnimate()   // [0, 200]
    .startAnimate(500).… .endAnimate(); // [200, 700]
```

使用 `after(t)` 可指定起始时刻：

```js
rect.after(400) // 起始 400 ms
    .startAnimate(500)
    .x(50)
    .endAnimate(); // 区间 [400, 900]
```

暂停并等待用户按 `N` 继续：

```js
rect1.startAnimate(300).x(100).endAnimate();
rect2.after(300).startAnimate(300).y(100).endAnimate();
await sd.pause(); // 暂停，之后时间轴清零
rect1.startAnimate(200).x(200).endAnimate(); // [0, 200]
```

默认动画时长 300 ms；如无特殊需求，优先使用默认值。

## 画布与坐标

-   固定尺寸：1200 × 600 px，不可修改
-   左上角 (0, 0)，右下角 (1200, 600)
-   元素尽量居中，避免遮挡，保持版式整洁

## 代码规范

```js
import * as sd from "@/sd";
const svg = sd.svg();
const C = sd.color();
const D = sd.device();
const I = sd.input();

sd.init(() => {
    /* 仅做静态属性初始化，禁止动画 */
});

sd.main(async () => {
    await sd.pause();
    rect.startAnimate().x(100).y(100).endAnimate();
    await sd.pause();
    rect.startAnimate().width(100).height(100).endAnimate();
});
```

布局顺序：先确定尺寸，再定位中心，避免二次偏移。

```js
rect.width(50).cx(80); // 中心精准落在 80
```

## 颜色

```js
const C = sd.color();
rect.startAnimate(300).color(C.red).endAnimate(); // 填充红
circle.startAnimate(400).fill(C.purple).endAnimate(); // 填充紫
ellipse.startAnimate(500).stroke(C.green).endAnimate(); // 描边绿
polygon.startAnimate(350).color(C.BLUE).endAnimate(); // 蓝色系（填充浅蓝色，描边深蓝色）
```

-   大写名称（如 `C.BLUE`）同时设置填充与描边
-   小写名称（如 `C.red`）仅返回单一色值，具体作用取决于调用方法（`fill` / `stroke`）

## 动画风格指南

-   像播放一段完整视频，节奏流畅、画面精美、知识准确
-   采用和谐浅色配色，元素丰富，版式平衡，杜绝遮挡
-   优先使用浮现、生长、强调等微动效，避免生硬跳变

示例动效：

```js
// 横向浮现
new sd.Text(svg, "Hello").opacity(0).x(500).y(100).startAnimate(300).x(510).opacity(1).endAnimate();

// 文字切换
text.startAnimate(200).opacity(0).endAnimate().text("World").startAnimate(200).opacity(1).endAnimate();

// 圆形弹出
new sd.Circle(svg).cx(600).cy(200).r(0).color(C.GREEN).startAnimate().r(20).endAnimate();

// 强调变色
text.startAnimate(300)
    .fontSize(25)
    .color(C.red)
    .cx(100)
    .endAnimate()
    .startAnimate(300)
    .fontSize(20)
    .color(C.black)
    .cx(100)
    .endAnimate();
```
