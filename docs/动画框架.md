# SD 动画框架

## 动画框架引入

使用一行代码 `import * as sd from "@/sd";`，即可完成引入

## 动画框架简介

SD 动画框架在 SVG 之上提供轻量级对象封装，将原始 SVG 元素映射为链式 JS 对象。以矩形为例：

```js
const svg = sd.svg(); // 1200×600 画布
const rect = new sd.Rect(); // 创建矩形
rect.setX(100).setWidth(30); // 链式设置属性
svg.appendChild(rect); // 将 rect 添加到画布上
```

读取属性时，调用 get 方法：

```js
console.log(rect.getX()); // 100
```

你可以在创建对象时，使用 config 字典快速完成属性设置：

```js
const svg = sd.svg();
const rect = new sd.Rect({
    targetNode: svg,
    x: 100,
    y: 100,
    width: 30,
    height: 60,
}); // 无需调用 svg.appendChild(rect) 了
```

# 动画

动画框架提供关键帧动画和逐帧动画，这两种动画的制作，并且它们是互斥的，选了一个就不能用另一个了

## 关键帧动画

一般使用 `sd.main` 来引导关键帧动画：

```ts
sd.main(async () => {
    await sd.pause();
    rect.startAnimate().setX(100).setY(100).endAnimate(); // 创建一个关键帧动画，对 x 和 y 并行进行关键帧动画，使用默认配置（delay = 0ms，duration = 300ms）
    await sd.pause();
    rect.startAnimate().setWidth(100).setHeight(100).endAnimate(); // 创建一个关键帧动画，对 width 和 height 并行进行关键帧动画，使用默认配置
});
```

把属性修改置于 `startAnimate` / `endAnimate` 之间即可生成关键帧动画：

```ts
rect.startAnimate({
    delay: 0,
    duration: 300,
}) // 0 ms 开始，持续 300 ms
    .setX(100) // 目标值
    .setWidth(30)
    .endAnimate();
```

多段动画按声明顺序依次执行：

```ts
rect.startAnimate({
    delay: 0,
    duration: 300,
})
    .setX(100)
    .endAnimate(); // [0, 200]
rect.startAnimate({
    delay: 200,
    duration: 500,
})
    .setX(200)
    .endAnimate(); // [200, 700]
```

注意，禁止对一个属性做时间线上有重合的关键帧动画，这种行为的结果是无法预测的

暂停并等待用户按 `N` 继续：

```ts
rect1.startAnimate({ delay: 0, duration: 300 }).setX(100).endAnimate();
rect2.startAnimate({ delay: 300, duration: 300 }).setY(100).endAnimate();
await sd.pause(); // 暂停
rect1.startAnimate({ duration: 200 }).setX(200).endAnimate(); // [0, 200]
```

默认动画时长 300 ms；如无特殊需求，优先使用默认值。

关键帧动画在框架下，是自动可逆的

## 逐帧动画

使用 sd.loopUpdate 来完成逐帧动画，逐帧动画不可使用 startAnimate 和 endAnimate 机制，直接开始 set 各种属性就行了

```ts
sd.loopUpdate((t: number) => {
    // 逐帧动画更新
    // t 是一个从 0 开始的时间，单位是毫秒
    // 该函数每一帧都会调用一次
});
```

## 画布与坐标

-   固定尺寸：1200 × 600 px，不可修改
-   左上角 (0, 0)，右下角 (1200, 600)
-   元素尽量居中，避免遮挡，保持版式整洁

## 代码规范

使用 const 替换 let，尽量让所有的变量都使用 const 定义，const 优先

## 可用对象速览

### Text

可调节参数：

-   内置参数：opacity，fill，fillOpacity，stroke，strokeOpacity，strokeWidth，strokeDashArray，strokeDashOffset，fontSize，text，fontFamily(只能选"Times New Roman"或者"Arial")
-   其他参数：centerX，centerY，maxX，maxY，width，height

### Rect

可调节参数：

-   内置参数：opacity，fill，fillOpacity，stroke，strokeOpacity，strokeWidth，strokeDashArray，strokeDashOffset，x，y，width，height，rx，ry
-   其他参数：centerX，centerY，maxX，maxY

### Circle

可调节参数：

-   内置参数：opacity，fill，fillOpacity，stroke，strokeOpacity，strokeWidth，strokeDashArray，strokeDashOffset，centerX，centerY，r
-   其他参数：x，y，maxX，maxY，width，height

### Ellipse

可调节参数：

-   内置参数：opacity，fill，fillOpacity，stroke，strokeOpacity，strokeWidth，strokeDashArray，strokeDashOffset，centerX，centerY，rx，ry
-   其他参数：x，y，maxX，maxY，width，height

### Line

可调节参数：

-   内置参数：opacity，fill，fillOpacity，stroke，strokeOpacity，strokeWidth，strokeDashArray，strokeDashOffset，x1，y1，x2，y2
-   其他参数：x，y，width，height

### Filter

用来容纳一个 filter 组合的，其内部可以 appendChild

-   参数：id，x，y，width，height

### GaussianBlur

可调节参数：

-   参数：in，out，stdDeviation

### Offset

可调节参数：

-   参数：in，out，dx，dy

### DropShadow

可调节参数：

-   参数：in，out，stdDeviation，dx，dy

### Composite

可调节参数：

-   参数：in，in2，out，operator，k1，k2，k3，k4

### ColorMatrix

可调节参数：

-   参数：in，out，type，values

### Blend

可调节参数

-   参数：in，in2，out，mode

## 布局说明

以 circle 为例子，circle 元素本身是没有 x，y，width，height 属性的，当你获取它的 x 属性时，实际上是通过 cx - r 算出来的一个值；同理，当你设置它的 x 属性时，也是对其现有的 x 属性与设置的 x 属性的差值进行偏移

布局顺序：先确定尺寸，再定位中心，避免二次偏移。

```js
rect.setWidth(50).setCenterX(80); // 中心精准落在 80
```

## 颜色

```js
const C = sd.color();
rect.startAnimate(300).setColor(C.red).endAnimate(); // 填充红
circle.startAnimate(400).setFill(C.purple).endAnimate(); // 填充紫
ellipse.startAnimate(500).setStroke(C.green).endAnimate(); // 描边绿
polygon.startAnimate(350).setColor(C.BLUE).endAnimate(); // 蓝色系（填充浅蓝色，描边深蓝色）
```

-   大写名称（如 `C.BLUE`）同时设置填充与描边
-   小写名称（如 `C.red`）仅返回单一色值，具体作用取决于调用方法（`fill` / `stroke`）

## 动画风格指南

-   像播放一段完整视频，节奏流畅、画面精美、知识准确
-   采用和谐浅色配色，元素丰富，版式平衡，杜绝遮挡
-   优先使用浮现、生长、强调等微动效，避免生硬跳变
