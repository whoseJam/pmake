# 嵌入动画

嵌入 PPT 的动画需遵循“零说明文字”原则：所有解释性内容移至 PPT，动画仅呈现符号化数据（如 `dis[u]`、`d`、`f`）。

## 语言与字幕规范

-   禁止出现中文及完整英文句子
-   禁止使用 `sd.Caption`
-   仅允许符号化文本
-   说明性内容由 PPT 承载
-   `sd.pause()` 不传参，强制手动触发，步进节奏与演讲同步

请你只使用库提供的最基础的 svg 图形和路径，完成动画的创作

当你想要使用更复杂的结构的时候，你可以自定义组件，组件里面一定要实现响应式布局，管理好 x,y,width 和 height

## 自定义组件指南

自定义组件通常通过继承 `sd.SDNode` 来实现。这允许你的组件利用框架提供的动画、布局和事件系统。

### 1. 继承结构

```typescript
import * as sd from "@/sd";

export class MyComponent extends sd.SDNode {
    constructor(target) {
        super(target);
        // 初始化组件内容
    }
}
```

### 2. SDNode 已提供的功能

继承 `SDNode` 后，你的组件自动获得以下能力，**无需重复实现**：

-   **基础变换**：`x()`, `y()`, `width()`, `height()`, `scale()`, `rotate()`, `opacity()` 等属性的管理与动画。
-   **动画系统**：`startAnimate()`, `endAnimate()`, `after()`, `delay()`, `duration()` 等链式动画调用。
-   **层级管理**：`layer()`, `newLayer()`, `attachTo()`，以及自动的 DOM 挂载。
-   **子节点管理**：`childAs()`, `child()`, `eraseChild()`，用于管理内部构件。
-   **响应式布局**：`rule()` 方法，允许外部定义组件的布局规则。
-   **事件系统**：`onClick()`, `onDblClick()`, `drag()` 等交互事件。
-   **常用效果**：`appear()`, `disappear()`, `fadeIn()`, `fadeOut()` 等预设动画。

### 3. 需要你自己编写的部分

在自定义组件中，你通常需要关注以下内容：

-   **内部结构组合**：在构造函数中创建并添加子节点（如 `Rect`, `Text`, `Circle` 等）。
-   **内部布局逻辑**：使用 `childAs` 的第三个参数（布局规则）来定义子节点如何随组件本身（`this`）的 `x, y, width, height` 变化而变化。
-   **自定义属性/方法**：暴露组件特有的业务逻辑接口（例如 `setTitle()`, `setValue()`）。

### 4. 示例：带标签的矩形

这是一个组合了矩形和文本的简单组件示例。它展示了如何利用响应式布局让文本始终居中于矩形。

```typescript
import * as sd from "@/sd";

export class LabeledRect extends sd.SDNode {
    constructor(target) {
        super(target);

        // 1. 创建内部子节点
        // 注意：传入 'this' 作为 target，将其挂载到当前组件的层级下
        const bg = new Rect(this).fill(Color.blue).opacity(0.5);
        const label = new Text(this).fill(Color.white).fontSize(20);

        // 2. 注册子节点并定义响应式布局规则

        // 背景矩形跟随组件本身的位置和大小
        this.childAs("bg", bg, (parent, child) => {
            child.x(parent.x()).y(parent.y()).width(parent.width()).height(parent.height());
        });

        // 文本始终位于组件中心
        this.childAs("label", label, (parent, child) => {
            child.center(parent.center());
        });

        // 设置默认大小
        this.width(100).height(60);
    }

    // 3. 自定义业务方法
    setText(content: string) {
        // 获取子节点并类型断言
        this.child("label").text(content);
        return this; // 返回 this 以支持链式调用
    }

    setBgColor(color: string) {
        this.child("bg").fill(color);
        return this;
    }
}
```

**使用方式：**

```typescript
const myBox = new LabeledRect(scene)
    .x(100)
    .y(100)
    .setText("Hello")
    .startAnimate()
    .width(200) // 动画过程中，背景变宽，文字自动保持居中
    .endAnimate();
```

### 5. 示例：动态连接线（使用 effect）

`effect` 方法允许你定义更复杂的响应式逻辑，甚至可以跨越组件层级追踪依赖。下面的示例展示了一个始终连接两个节点的线段组件。

```typescript
import * as sd from "@/sd";

export class DynamicLink extends sd.SDNode {
    /**
     * @param target - 挂载目标
     * @param nodeA - 连接的起始节点
     * @param nodeB - 连接的结束节点
     */
    constructor(target, nodeA, nodeB) {
        super(target);

        // 1. 创建内部的线段
        const line = new Line(this).stroke(Color.black).strokeWidth(2);
        this.childAs("line", line);

        // 2. 使用 effect 定义响应式逻辑
        // 当 nodeA 或 nodeB 的位置（center）发生变化时，自动更新线段的端点
        this.effect("updateLink", () => {
            const p1 = nodeA.center();
            const p2 = nodeB.center();
            this.child("line").source(p1).target(p2);
        });
    }
}
```

**使用方式：**

```typescript
const rect1 = new Rect(svg).x(100).y(100).width(50).height(50);
const rect2 = new Rect(svg).x(300).y(200).width(50).height(50);

// 创建连接线
const link = new DynamicLink(svg, rect1, rect2);

// 当 rect1 或 rect2 移动时，连接线会自动更新
rect1.startAnimate().x(150).endAnimate();
```
