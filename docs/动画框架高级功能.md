# 动画框架高级功能

动画框架支持通过继承 `sd.Group` 来创建高级自定义组件。`Group` 组件作为一个容器，可以包含多个子节点，并管理它们的布局和动画。

## 自定义组件示例

以下是一个自定义 `TextBox` 组件的示例，它包含一个矩形背景和一个文本节点。

> **⚠️ 易错点提醒**：
>
> 1. **所有私有变量都必须存储在 `this.vars` 中**，这样才能享受响应式系统的好处
> 2. 必须在构造函数末尾初始化 `width` 和 `height`

```javascript
class TextBox extends sd.Group {
    constructor(target, content = "hello", width = 50, height = 50) {
        super(target);

        // 创建子节点
        const rect = new sd.Rect(this);
        const text = new sd.Text(this, content);

        // 将子节点添加到当前 Group 中
        this.add(rect);
        this.add(text);

        // ⚠️ 关键：将私有变量存储在 this.vars 中，方便后续访问
        // 这样可以享受响应式系统的好处
        this.vars.merge({
            rect: rect,
            text: text,
        });

        // 定义响应式布局
        // 当组件的 x, y, width, height 发生变化时，自动更新子节点
        this.effect("layout", () => {
            // 背景矩形跟随组件的大小和位置
            rect.width(this.width()).height(this.height()).x(this.x()).y(this.y());
            // 或者使用布局辅助函数: L.BackgroundLayout(this, rect);

            // 文本居中显示
            text.center(this.cx(), this.cy());
            // 或者使用布局辅助函数: L.CenterLayout(this, text);
        });

        // ⚠️ 关键步骤：必须初始化宽高，否则组件初始尺寸为 0
        // 这会触发 effect("layout")，将尺寸传递给子节点
        this.width(width).height(height);
    }

    // 辅助方法：获取内部矩形节点
    getRect() {
        return this.vars.rect;
    }

    // 辅助方法：获取内部文本节点
    getText() {
        return this.vars.text;
    }
}
```

当对一个 `Group` 实例调用 `startAnimate` 时，它会自动激活该组内所有子节点的动画。

## 动态尺寸组件（增长型组件）

对于大小随内容变化的组件（如数组、树等），你需要手动维护组件的宽高。

> **⚠️ 易错点提醒**：
>
> 1. **必须在构造函数中初始化 `width` 和 `height`**，即使内容为空也要设置初始值
> 2. 在添加/删除元素时，**必须把存储元素的数组作为响应式变量定义**，否则响应式作用不会随着更新/删除而被触发
> 3. 当添加/删除元素时，**必须手动更新组件尺寸**，以防其他组件在利用当前组件的宽高做布局的时候出错
> 4. **宽高维护原则：永远应该是父组件的宽高+其他信息决定子组件的宽高，而不应该是子组件的宽高决定父组件的宽高**

以一个简单的数组组件为例：

```javascript
class MyArray extends sd.Group {
    constructor(target, data = [1, 2, 3, 4, 5]) {
        super(target);

        // 定义自定义响应式变量
        this.vars.merge({
            widthPerElement: 60,
            // ⚠️ 关键：必须将元素数组定义为响应式变量，否则数组变化不会触发 effect
            elements: [...（根据data进行初始化）],
        });


        // ⚠️ 关键步骤：必须初始化宽度，否则组件初始宽度为 0
        this.width(data.length * this.vars.widthPerElement);

        // 定义布局逻辑
        this.effect("layout", () => {
            // ⚠️ 在这里根据子元素的实际布局更新组件的 width 和 height
            // 例如：this.width(lastElement.mx() - firstElement.x());
            // 例如：this.height(maxElementHeight);
            // 例如：L.ArrayLayout(this.vars.elements, { elementWidth: this.vars.widthPerElement, x: this.x(), y: this.y() });
        });
    }

    pushElement(element) {
        // 添加元素到响应式数组中
        this.vars.elements.push(element); // ⚠️ 使用 this.vars.elements，不是 this._.elements

        // ⚠️ 关键步骤：添加元素后必须更新组件宽度
        // 这才能保证其他组件，在考察当前组件的宽度时，布局不会出错
        this.width(this.vars.elements.length * this.vars.widthPerElement);
    }

}
```

### 宽高维护原则 ⚠️

**核心原则**：永远应该是父组件的宽高+其他信息决定子组件的宽高，而不应该是子组件的宽高决定父组件的宽高。

这个原则确保了组件的尺寸计算是单向的、可预测的，避免循环依赖和布局混乱。

#### ✅ 正确示例：父组件决定子组件

```javascript
class MyArray extends sd.Group {
    constructor(target) {
        super(target);

        this.vars.merge({
            elements: [],
            elementWidth: 50, // 父组件定义的参数
        });

        this.width(0).height(50);

        // ✅ 正确：父组件的宽度由自身的响应式变量计算
        this.effect("calcWidth", () => {
            // 父组件根据自己的状态（elements数量 + elementWidth）计算宽度
            this.vars.width = this.vars.elements.length * this.vars.elementWidth;
        });

        // ✅ 正确：子元素的位置和尺寸由父组件决定
        this.effect("layout", () => {
            const elements = this.vars.elements;
            for (let i = 0; i < elements.length; i++) {
                // 子元素的 x, y, width, height 都由父组件的参数决定
                elements[i].x(this.x() + i * this.vars.elementWidth);
                elements[i].y(this.y());
                elements[i].width(this.vars.elementWidth);
                elements[i].height(this.height());
            }
        });
    }
}
```

#### ❌ 错误示例：子组件决定父组件

```javascript
class MyArray extends sd.Group {
    constructor(target) {
        super(target);

        this.vars.merge({
            elements: [],
        });

        // ❌ 错误：试图根据子元素的宽度来计算父组件宽度
        this.effect("calcWidth", () => {
            let totalWidth = 0;
            for (const elem of this.vars.elements) {
                totalWidth += elem.width(); // 读取子元素的宽度
            }
            this.vars.width = totalWidth; // 用子元素宽度决定父组件宽度
        });

        // ❌ 问题：这会导致循环依赖
        // 当父组件宽度变化时，可能触发子元素重新布局
        // 子元素布局变化又会触发父组件宽度重新计算
        // 形成死循环或不可预测的行为
    }
}
```

**为什么这个原则很重要**：

1. **避免循环依赖**：如果父组件依赖子组件的尺寸，而子组件又依赖父组件的布局，会形成循环
2. **保证可预测性**：单向的尺寸流动使得布局行为更容易理解和调试
3. **提升性能**：避免不必要的重复计算和布局更新
4. **符合组件设计原则**：父组件应该控制子组件，而不是反过来

### 响应式变量的正确使用 ⚠️

**关键原则**：存储元素的数组必须作为响应式变量定义在 `this.vars` 中，而不是 `this._` 中。

#### ❌ 错误示例：将元素数组存储在 `this._` 中

```javascript
class MyArray extends sd.Group {
    constructor(target) {
        super(target);

        // ❌ 错误：将元素数组存储在 this._ 中
        this._.elements = [];

        this.vars.merge({
            cellWidth: 50,
        });

        this.width(0).height(50);

        // ❌ 问题：当 this._.elements 变化时，这个 effect 不会被触发！
        this.effect("layout", () => {
            const elements = this._.elements;
            for (let i = 0; i < elements.length; i++) {
                elements[i].x(this.x() + i * this.vars.cellWidth);
                elements[i].y(this.y());
            }
        });
    }

    push(value) {
        const cell = new Cell(this, value);
        this.add(cell);

        // ❌ 问题：修改 this._.elements 不会触发 effect("layout")
        // 导致新添加的元素不会自动布局！
        this._.elements.push(cell);
        this.width(this._.elements.length * this.vars.cellWidth);
    }
}
```

**问题分析**：

-   `this._` 中的变量是普通变量，修改它们不会触发 `effect`
-   添加元素后，虽然更新了 `width`（会触发 effect），但 effect 中读取的 `this._.elements` 已经是新数组了
-   框架无法追踪 `this._.elements` 的变化，导致响应式失效

#### ✅ 正确示例：将元素数组存储在 `this.vars` 中

```javascript
class MyArray extends sd.Group {
    constructor(target) {
        super(target);

        // ✅ 正确：将元素数组作为响应式变量定义
        this.vars.merge({
            cellWidth: 50,
            elements: [], // 响应式数组
        });

        this.width(0).height(50);

        // ✅ 当 this.vars.elements 变化时，这个 effect 会自动触发
        this.effect("layout", () => {
            const elements = this.vars.elements;
            for (let i = 0; i < elements.length; i++) {
                elements[i].x(this.x() + i * this.vars.cellWidth);
                elements[i].y(this.y());
            }
        });
    }

    push(value) {
        const cell = new Cell(this, value);
        this.add(cell);

        // ✅ 正确：修改响应式数组会触发 effect("layout")
        // 新元素会自动布局到正确位置
        this.vars.elements.push(cell);
        this.width(this.vars.elements.length * this.vars.cellWidth);
    }
}
```

**为什么这样是正确的**：

-   `this.vars.elements` 是响应式变量，框架会追踪它的变化
-   当调用 `this.vars.elements.push()` 时，框架会自动触发相关的 `effect`
-   布局逻辑会自动执行，新元素会被正确定位

#### 更多对比例子

**场景：删除元素**

```javascript
// ❌ 错误：从 this._ 中删除
removeElement(index) {
    this._.elements.splice(index, 1); // 不会触发 effect
    this.width(this._.elements.length * this.vars.cellWidth);
    // 元素虽然被删除，但其他元素不会自动重新布局！
}

// ✅ 正确：从 this.vars 中删除
removeElement(index) {
    this.vars.elements.splice(index, 1); // 会触发 effect
    this.width(this.vars.elements.length * this.vars.cellWidth);
    // 其他元素会自动重新布局到正确位置
}
```

**场景：清空所有元素**

```javascript
// ❌ 错误
clear() {
    this._.elements = []; // 不会触发 effect
    this.width(0);
}

// ✅ 正确
clear() {
    this.vars.elements = []; // 会触发 effect
    this.width(0);
}
```

**场景：批量更新元素**

```javascript
// ❌ 错误
updateColors() {
    for (const elem of this._.elements) {
        elem.color(C.red); // 每个元素单独更新，效率低
    }
}

// ✅ 正确：利用响应式变量和 Group 动画
updateColors() {
    this.startAnimate(); // 激活组内所有元素的动画
    for (const elem of this.vars.elements) {
        elem.color(C.red); // 统一动画
    }
    this.endAnimate();
}
```

## 响应式变量 (Vars)

框架在 `vars` 对象中内置了 `x`, `y`, `width`, `height` 四个核心响应式变量，并提供了对应的 getter 和 setter 方法。

> **⚠️ 易错点提醒**：
>
> 1. 调用 `this.width()` 是获取值，调用 `this.width(100)` 是设置值
> 2. 设置响应式变量会自动触发相关的 `effect` 函数
> 3. 不要直接修改 `this.vars.width`，应该使用 `this.width(value)` 方法

### 内置变量定义

```typescript
// x 坐标
x(): number;
x(val: number): this;

// y 坐标
y(): number;
y(val: number): this;

// 宽度
width(): number;
width(val: number): this;

// 高度
height(): number;
height(val: number): this;
```

### 赋值精度控制

在更新 `vars` 中的变量时，除了直接赋值，还可以使用不同精度的赋值方法来优化性能，避免微小变化触发不必要的重绘或计算。

-   **`lpset` (Low Precision Set)**: 低精度赋值。如果新值与旧值的差值在 **1** 以内，则认为没有变化。
-   **`mpset` (Medium Precision Set)**: 中等精度赋值。如果新值与旧值的差值在 **0.1** 以内，则认为没有变化。
-   **`hpset` (High Precision Set)**: 高精度赋值。如果新值与旧值的差值在 **0.01** 以内，则认为没有变化。

> **⚠️ 使用场景提醒**：
>
> -   在动画过程中频繁更新位置时，使用精度控制可以显著提升性能
> -   对于需要精确定位的场景（如像素级对齐），不要使用精度控制
> -   精度控制只影响是否触发 `effect`，不影响实际存储的值

使用示例：

```javascript
// 如果原值为 100，新值 100.5 与原值差值小于 1，不会触发 effect
this.vars.lpset("x", 100.5);

// 如果原值为 100，新值 101.5 与原值差值大于 1，会触发 effect
this.vars.lpset("x", 101.5);
```
