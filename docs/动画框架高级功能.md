# 动画框架高级功能

动画框架提供了强大的高级功能，包括响应式系统、动画生命周期管理、以及复杂的组件交互机制。这些功能让开发者能够创建动态、交互性强的可视化动画。

## 1. 响应式系统

响应式系统是动画框架的核心特性，它提供了两种响应式机制：组件内部响应式和父子组件响应式。通过响应式系统，组件能够自动响应数据变化并更新布局和外观。

### 1.1 组件内部响应式

组件可以通过 `effect` 方法定义内部响应式逻辑。当组件的响应式属性发生变化时，关联的 effect 会自动触发，执行相应的更新逻辑。

#### 核心概念

-   **响应式属性**：存储在 `this.vars` 中的属性，支持自动追踪依赖
-   **Effect 函数**：定义属性变化时的响应逻辑
-   **自动依赖追踪**：框架自动追踪 effect 中访问的响应式属性

#### 基本用法

```typescript
class Component extends sd.SDNode {
    constructor(target) {
        super(target);

        // 定义响应式属性
        this.vars.merge({
            x: 0,
            y: 0,
            width: 100,
            height: 50,
            color: "#3498db",
        });

        // 定义响应式 effect
        this.effect("layout", () => {
            // 当 x, y, width, height 变化时自动执行
            this.updatePosition();
            this.updateSize();
        });

        this.effect("appearance", () => {
            // 当 color 变化时自动执行
            this.updateColor();
        });
    }
}
```

#### 高级示例：Array 组件

```typescript
export class Array extends sd.SDNode {
    constructor(target: SDNode | RenderNode) {
        super(target);

        this.type("Array");

        // 定义响应式属性
        this.vars.merge({
            x: 0, // 数组起始 x 坐标
            y: 0, // 数组起始 y 坐标
            elementWidth: 40, // 元素宽度
            elementHeight: 40, // 元素高度
            spacing: 5, // 元素间距
            data: [], // 数组数据
        });

        // 定义数组布局 effect
        this.effect("arrayLayout", () => {
            this.forEachElement((element, index) => {
                const i = this.__idx(index);
                this.tryUpdate(element, () => {
                    const elementNode = element as Box;
                    const xOffset = i * (this.elementWidth() + this.spacing());

                    // 自动计算每个元素的位置
                    elementNode
                        .x(this.x() + xOffset)
                        .y(this.y())
                        .width(this.elementWidth()) // elementWidth 实际上调用了 this.vars.elementWidth
                        .height(this.elementHeight()); // elementHeight 实际上调用了 this.vars.elementHeight
                });
            });
        });

        // 定义数据变化 effect
        this.effect("dataUpdate", () => {
            const data = this.data();
            // 根据数据变化更新元素内容
            this.syncElementsWithData(data);
        });
    }
}
```

#### Effect 生命周期管理

```typescript
// 定义 effect
this.effect("myEffect", () => {
    console.log("Effect triggered");
});

// 手动触发 effect
this.triggerEffect("myEffect");

// 检查 effect 是否存在
if (this.hasEffect("myEffect")) {
    console.log("Effect exists");
}

// 移除特定 effect
this.uneffect("myEffect");

// 移除所有 effects
this.uneffectAll();
```

### 1.2 父子组件响应式

父子组件响应式通过 `childAs` 方法实现，它定义了子组件如何随父组件的变化而自动调整。这种机制支持复杂的组件层次结构和布局关系。

#### 基本用法

```typescript
const parent = new Container(svg);
const child = new Box(svg);

// 定义父子响应式关系
parent.childAs(child, (parent: SDNode, child: SDNode) => {
    // 子组件居中于父组件
    child.center(parent.center());

    // 子组件宽度为父组件的 80%
    child.width(parent.width() * 0.8);

    // 子组件高度固定
    child.height(50);
});
```

#### 命名子组件

```typescript
// 为子组件指定名称，便于后续访问
parent.childAs("header", headerComponent, (parent, child) => {
    child.x(parent.x());
    child.y(parent.y());
    child.width(parent.width());
    child.height(30);
});

// 通过名称访问子组件
const header = parent.child("header");
```

#### 响应式规则的类型定义

```typescript
type SDRule = (parent: SDNode, child: SDNode) => void;
```

响应式规则定义了子组件相对于父组件的布局和行为关系。规则在以下时机自动执行：

-   父组件的响应式属性发生变化
-   子组件首次添加到父组件
-   手动触发更新

#### 实际应用示例

```typescript
// 创建坐标轴系统
const coord = new CartesianCoord(svg);
const xAxis = new Axis(svg);
const yAxis = new Axis(svg);

// 定义坐标轴的响应式布局
coord.childAs("x", xAxis, (parent, child) => {
    child.x(parent.x());
    child.y(parent.y() + parent.height());
    child.width(parent.width());
});

coord.childAs("y", yAxis, (parent, child) => {
    child.x(parent.x());
    child.y(parent.y());
    child.height(parent.height());
});
```

### 1.3 响应式系统原理

#### 依赖追踪机制

响应式系统基于以下核心原理：

1. **Proxy 代理**：使用 ES6 Proxy 拦截属性访问和修改
2. **依赖收集**：在 effect 执行过程中自动收集访问的响应式属性
3. **变化通知**：当响应式属性变化时，通知相关的 effects 重新执行
4. **批量更新**：优化性能，批量执行相关的 effects

#### 性能优化

-   **惰性计算**：只有在需要时才计算 effect
-   **去重机制**：避免重复执行相同的 effect
-   **冻结机制**：可以临时冻结响应式更新，批量操作后再统一更新

## 2. 动画生命周期管理

动画框架提供了完整的生命周期管理机制，包括进入动画、退出动画和状态管理。

### 2.1 进入和退出动画

进入和退出动画允许你定义组件在添加到场景或从场景移除时的动画效果。

#### 进入动画示例

```typescript
function createEnterAnimation(parent, child, moveCallback) {
    child
        .startSubAnimate() // 开启子动画
        .subAnimate(0, 0) // 子动画时间区间 [0, 0]
        .opacity(0) // 初始透明度为 0（隐藏）
        .attachTo(parent) // 将子节点附加到父节点
        .execute(moveCallback) // 执行布局函数
        .subAnimate(0, 1) // 子动画时间区间 [0, 1]
        .opacity(1) // 淡入到完全不透明
        .endSubAnimate(); // 结束子动画
}
```

#### 退出动画示例

```typescript
function createExitAnimation(parent, child) {
    child
        .startSubAnimate()
        .subAnimate(0, 1)
        .opacity(1) // 开始时不透明
        .subAnimate(1, 2) // 动画持续时间
        .opacity(0) // 淡出到透明
        .endSubAnimate()
        .remove(); // 从场景中移除
}
```

#### 使用 onEnter 和 onExit

```typescript
const component = new MyComponent(svg);

// 设置进入动画
component.onEnter((parent, child, move) => {
    createEnterAnimation(parent, child, move);
});

// 设置退出动画
component.onExit((parent, child) => {
    createExitAnimation(parent, child);
});
```

### 2.2 子动画系统

子动画系统允许在主要动画时间轴内创建嵌套的动画区间。

#### 子动画时间模型

```typescript
// 主动画时间轴: [0, 1000ms]
component
    .startAnimate(1000)
    .x(100) // [0, 1000ms]

    // 子动画: 在主动画的 [200ms, 800ms] 区间内执行
    .startSubAnimate()
    .subAnimate(0.2, 0.8) // 相对时间: 20% 到 80%
    .opacity(0.5)
    .endSubAnimate()

    .endAnimate();
```

#### 复杂子动画序列

```typescript
component
    .startAnimate(2000)
    // 第一阶段：移动
    .x(200)
    .y(100)

    // 第二阶段：大小变化 + 颜色变化（并行）
    .startSubAnimate()
    .subAnimate(0.3, 0.7)
    .width(150)
    .height(150)
    .color("#e74c3c")
    .endSubAnimate()

    // 第三阶段：旋转
    .startSubAnimate()
    .subAnimate(0.7, 1.0)
    .rotate(360)
    .endSubAnimate()

    .endAnimate();
```
