# 单体动画

独立讲解视频：用 `sd.Caption` 双语字幕，手动 `sd.pause()` 控制节奏。

```js
caption.startAnimate().caption("HDR 是一种新的显示技术", "HDR is a new tech for displaying").endAnimate();
await sd.pause(1000);
caption
    .startAnimate()
    .caption("它的出现丰富了人类在显示屏上的视觉感受", "It enhance the visual expr of human on display screen")
    .endAnimate();
```

-   画面变化越密，停顿越长；节奏与语音同步。
-   除双语字幕外，动画内禁止出现中文及解释性英文，仅允许符号化文本（如 `dis[u]`、`d`、`f`）。
